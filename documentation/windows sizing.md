*Updated 2 October, 2025*

When display is set to 200% in Windows Settings, screen captures will be at 6/7 size in terms of pixels.

For example a 230px-wide panel will be 197px wide in the screen capture.

### Mac/PC Differences

The default panel in Windows is 230px wide, compared to 240px on macOS:
- paragraph
- transform
- etc.
