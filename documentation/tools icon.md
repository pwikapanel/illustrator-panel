### Svija Tools Icon

When the user folds the panel in Illustrator, it is reduced to an icon, with or without text.

It is possible to use an SVG file for this icon, but on 23 July 2024 Adobe requested:

> Please include plugin icons of 48x48 and 192x192 px and submit a metadata change request to publish these.
