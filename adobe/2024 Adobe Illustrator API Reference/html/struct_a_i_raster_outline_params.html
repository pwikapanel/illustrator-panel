Detailed Description

Parameters for controlling the curve fitting used when outlining a raster.

Keep parameters within valid ranges to avoid excessive performance impact. To reduce performance impact, try increasing smoothness and fidelity tolerance. See AIRasterSuite::ExtractOutline()
