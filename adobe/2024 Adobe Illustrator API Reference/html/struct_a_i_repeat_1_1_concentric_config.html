Detailed Description

Concentric repeat, repeats an art in a concentric fashion.

User can change its properties like changing number of instances inside, and Merge state which combines all arts such that the stroke of intersecting arts does not override the fill of those arts. With all these properties ConcentricConfig is constructed.
