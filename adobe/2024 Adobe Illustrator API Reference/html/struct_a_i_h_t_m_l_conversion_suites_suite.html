Detailed Description

This suite allows you to register an HTML conversion suite, implemented as AIHTMLConversionSuite.

See also:
SPSuitesSuite
  • Acquire this suite using SPBasicSuite::AcquireSuite() with the constants kAIHTMLConversionSuitesSuite and kAIHTMLConversionSuitesSuiteVersion.
