ai::UnicodeString PlatformAddFileFormatData::extension

A comma-delimited list of DOS-style extensions that are filtered in the Open dialog, or appended to the file name in the Saves As dialog.

For example, "ai,eps".

The list has a maximum of 31 characters, and each extension has a maximum of 5 characters.

ai::UnicodeString PlatformAddFileFormatData::title

The Pascal-type string shown in the file type menu of the Save As and Open dialog.

ai::int32 PlatformAddFileFormatData::titleOrder

The order of menu items if a plug-in adds multiple file formats.

Use 0 if the plug-in adds only one filter.

ai::int32 PlatformAddFileFormatData::type

The variable type is the 4 digit Macintosh file type identifier.

Windows plug-ins can ignore this.
