This folder contains the fonts used by your website.

The web fonts used by your website are located in “WOFF Files”.

::::::: INSTALL FONTS PROVIDED BY SVIJA :::::::

1 ————— Install provided fonts (Mac)

- Open Font Book (in your Applications)
- Cmd-O to add fonts
- Select all the fonts in your Svija project
  (in SYNC/SVIJA/Fonts/TTF & OTF)

2 ————— Install the provided fonts (PC)

Open the fonts folder in your Svija project
(in SYNC\SVIJA\Fonts\TTF & OTF)

- Select everything and press ctrl-C to copy
- Navigate to the C:\Windows\Fonts folder
- Ctrl-V to paste everything

Restart Adobe Illustrator

:::::::::::::: USE OTHER FONTS :::::::::::::::

1 ————— Where is the font located (Mac)?

- Open Font Book (in your Applications)
- Right-click on the font
- Select “Show in Finder...”

1 ————— Where is the font located (PC)?

- Navigate to the C:\Windows\Fonts folder
- Search for the name, or type the first letters

2 ————— TTC Fonts

For TTF and OTF fonts, go to step 3.

TTC fonts must be unpacked at:

    transfonter.org/ttc-unpack

3 ———— Create a WOFF file

- Go to convertio.co
- Click on “Choose Files” and select the TTF/OTF fonts
- Click on “Convert all to ▼” and select “Font › WOFF”
- Click on “Convert”
- Move the downloaded WOFF files into the “WOFF Files” folder

Note: you should only install WOFF files — no subfolders or other files.

4 ———— Activate the fonts in Svija Cloud

Once a page has been visited, missing fonts will appear in the font list.

- Go to Svija Cloud › Fonts
- Fill in either the “WOFF Filename” field, or
- Check “Google font”

For more information, visit tech.svija.com/fonts
