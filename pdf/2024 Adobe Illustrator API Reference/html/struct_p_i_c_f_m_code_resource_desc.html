unsigned char PICFMCodeResourceDesc::fEntryName[1]

The entry-point name, used to look up the address of the function to call within the fragment; allows a single code fragment to export more than one plug-in.

If the name is an empty string, the default entry point for the code fragment is used. The entry-point name must be an exported symbol of the code fragment.
