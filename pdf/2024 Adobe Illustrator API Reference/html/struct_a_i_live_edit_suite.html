AIAPI AIErr(* AILiveEditSuite::ChangeBeginNotify)(const ai::LiteralString &inFeatureName, AIReal inEPFOverrideValue)

Widget manipulating art interactively must call this method at the beginning of the manipulation session (mouse-down/touch-start).

Tools registered using RegisterLiveEditPluginTool() calls this automatically at appropriate time.

Parameters:
inFeatureName Feature name to be used in live editing session. This can be any unique string like tool or widget name. Must not be empty string.
inEPFOverrideValue Specify EPF (event processing frequency) override value for this manipulation session. Valid value range is from ai::LiveEdit::EPF::kMinimumLimitValue to ai::LiveEdit::EPF::kMaximumLimitValue. To use the global (default) EPF value use ai::LiveEdit::EPF::kUseGlobaLimitValue.
Note:
This call must be balanced with a later call to ChangeFinishNotify().
See also:
class StLiveEditBeginFinishChangeNotifyHelper
AIAPI AIErr(* AILiveEditSuite::ChangeContinueEndNotify)()

Widget manipulating art interactively must call this method when it ends processing a change event (mouse-drag/touch-move).

Note:
This call must be balanced with an earlier call to ChangeContinueStartNotify() and must occur after a call to ChangeBeginNotify() but before ChangeFinishNotify().

AIAPI AIErr(* AILiveEditSuite::RegisterLiveEditPluginTool)(AIToolHandle inPluginTool, const ai::LiteralString &inFeatureName, AIReal inEPFOverrideValue)

Register a plugin tool to participate in live editing.

Registering causes future tool usage to automatically make live edit calls ChangeBeginNotify(), ChangeContinueStartNotify(), ChangeContinueEndNotify() and ChangeFinishNotify() appropriately.

Parameters:
inPluginTool Tool handle of the plugin tool.
inFeatureName Feature name to be used in live editing session. This can be any unique string like tool or widget name. Must not be empty string.
inEPFOverrideValue Specify EPF (event processing frequency) override value for this tool. Valid value range is from ai::LiveEdit::EPF::kMinimumLimitValue to ai::LiveEdit::EPF::kMaximumLimitValue. To use the global (default) EPF value use ai::LiveEdit::EPF::kUseGlobaLimitValue.
Note:
Feature names starting with "ai::" are reserved for use by Adobe plugins.
See also:
AIToolSuite::AddTool(), DeregisterLiveEditPluginTool()
