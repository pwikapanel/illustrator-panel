AINotifierHandle AINotifierMessage::notifier

The notifier handle returned from AINotifierSuite::AddNotifier().

If more than one notifier is installed, can be used to determine the instance that should handle the message.

void* AINotifierMessage::notifyData

Data whose type depends on the type of notification being sent.

For instance, notifiers related to plug-in tools receive the AIToolHandle to which the notifier message refers.

const char* AINotifierMessage::type

The type of event for which the plug-in is being notified.

If more than one notifier type is installed, can be used alone or with the notifier reference to determine the best way to handle the call.
